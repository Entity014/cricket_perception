# คำถามสำหรับผู้เชี่ยวชาญ/ฟาร์มจิ้งหรีด — Growth-Stage Classification

> รวบรวมไว้เพื่อเก็บข้อมูลที่ยังขาดสำหรับการเปลี่ยนทิศทางโปรเจกต์จาก Behavior Classification → Growth-Stage Classification

## ✅ ตอบแล้ว

- **สายพันธุ์**: ฟาร์มเลี้ยงจิ้งหรีดสายพันธุ์เดียว (ยังไม่ทราบว่าเป็นสายพันธุ์อะไร — ควรถามชื่อสายพันธุ์ให้ชัดด้วย)
- **โครงสร้างบ่อ**: 1 บ่อ = 1 stage (แต่ละบ่อมีจิ้งหรีดระยะเดียวกันทั้งหมด ไม่ปนกัน)
- **จำนวน stage**: มี 4 stage (แต่ยังไม่รู้ชื่อ/นิยามของแต่ละ stage)
- **Egg stage**: ไม่นับไข่เป็น 1 ใน 4 stage (เริ่มนับจากฟักเป็นตัวอ่อน)
- **Modality**: ใช้ acoustic ล้วนเป็นสัญญาณจำแนก stage — temperature/humidity (จาก DHT22) เก็บไว้เป็นแค่ ref/context ไม่ได้ใช้เป็น feature จำแนก stage โดยตรง ดังนั้นถ้า stage แรกๆ ไม่มีเสียงจริงๆ จะเป็นข้อจำกัดของ scope โปรเจกต์ ไม่ใช่เอาสัญญาณอื่นมาแทน
- **บ่อที่ฟาร์มมีให้อัดเสียง**: มีครบทั้ง 4 stage ในวันเดียว — อัดเสียงครบทุก stage ได้ในการไปเยี่ยมครั้งเดียว ไม่ต้องไปหลายรอบ
- **Metadata อื่นจากฟาร์ม**: คิดว่าไม่น่ามี (ไม่มีบันทึกวันปล่อยไข่/ให้อาหาร/sensor เดิมให้ใช้ช่วย label) — ต้องพึ่ง label จากผู้เชี่ยวชาญ/บ่อโดยตรงเป็นหลัก

## ❓ ยังไม่ได้ตอบ (คำถามหลักที่จะถามพรุ่งนี้)

1. [ ] ชื่อ/นิยามของแต่ละ 4 stage ของจิ้งหรีด คืออะไร
2. [ ] ชื่อสายพันธุ์ที่ฟาร์มเลี้ยงคืออะไร
3. [ ] จิ้งหรีดเริ่มร้อง (chirp) ตอน stage ไหน

## 🕒 อื่นๆ (ไว้ถามภายหลัง ไม่เร่งด่วน)

- [ ] ตัวอ่อนระยะแรกมีเสียงอะไรให้ฟังได้บ้างไหม (เสียงเดิน/กัดอาหาร) หรือเงียบสนิท — เผื่อคำตอบข้อ 3 ออกมาว่า stage แรกไม่ร้องเลย
- [ ] ผู้เชี่ยวชาญจะยืนยัน stage ได้จากอะไร — ดูตัวจริง/สุ่มจับตัวอย่าง หรือดูจากบันทึกวันเลี้ยง (batch date) ของบ่อนั้น
- [ ] ถ้าใช้ batch date เป็น proxy label ต้องรู้ว่าฟาร์มมีบ่อกี่ batch/อายุต่างกันตอนนี้
- [ ] อนุญาตให้ติดตั้งอุปกรณ์ (ESP32 + mic) อัดเสียงต่อเนื่องในบ่อได้ไหม กี่วัน
- [ ] ถ้าเราจะอัดเสียงในบ่อที่มี stage ต่างกัน จะกระทบกับ baseline ที่ใช้ทำ hunger/mortality alert เดิมไหม (RMS/ACI baseline อาจต้อง calibrate แยกตาม stage ด้วย)
